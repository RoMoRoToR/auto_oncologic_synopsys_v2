# Инструмент сбора данных и фармакокинетического анализа (RAG-парсер)

Интеллектуальная система на базе ИИ для автоматического извлечения фармакокинетических параметров лекарственных средств из научных статей и веба. Проект использует технологию **RAG** (Retrieval-Augmented Generation), объединяя поиск в реальном времени с анализом полнотекстовых PDF-документов.

## Основные возможности

*   **Гибридный поиск:** Комбинирует возможности Tavily API (быстрые факты) и Google Scholar (глубокий поиск научных публикаций).
*   **Автоматический обход Paywall:** Интегрированная логика поиска прямых PDF-ссылок и поддержка зеркал Sci-Hub.
*   **Продвинутый парсинг PDF:** Использование `Docling` для конвертации сложных документов в Markdown с поддержкой OCR (распознавание текста в таблицах и картинках).
*   **Интеллектуальный анализ (YandexGPT):** Автоматическое структурирование данных через Yandex AI Studio с использованием трехэтапного запроса для максимальной точности.
*   **Извлекаемые параметры:**
    *   Период полувыведения (T1/2)
    *   Внутрииндивидуальная вариабельность (CVintra, %)
    *   Площадь под кривой (AUC)
    *   Максимальная концентрация (Cmax)
    *   Время достижения Cmax (tmax)
    *   Токсичность и LD50
    *   Классификация по БКС (BCS Class)

## Технологический стек

*   **LLM:** YandexGPT (через Yandex AI Studio SDK)
*   **Search Engines:** Tavily API, Google Scholar
*   **PDF Engine:** Docling, RapidOCR (ONNX)
*   **Язык:** Python 3.11+

## Установка

### Используя Conda (рекомендуется)

1. Клонируйте репозиторий.
2. Создайте окружение из файла `environment.yml`:
```bash
conda env create -f environment.yml
conda activate oncology_parser
```

### Используя Pip

```bash
pip install -r requirements.txt
```

*Примечание: Для корректной работы OCR на Windows рекомендуется установить `onnxruntime` или `onnxruntime-gpu`.*

## Настройка

Создайте файл `.env` в корневой папке проекта и добавьте ваши ключи:

```text
TAVILY_API_KEY=your_tavily_key
YANDEX_FOLDER_ID=your_folder_id
YANDEX_AUTH_KEY=your_auth_key
```

## Структура проекта

*   `src/collector.py` — Главный оркестратор (управляет логикой "Поиск -> Парсинг -> Анализ").
*   `src/extractor.py` — Модуль взаимодействия с YandexGPT.
*   `src/parser.py` — Модуль обработки PDF-документов через Docling.
*   `src/scholar_utils.py` — Утилиты для парсинга Google Scholar и Sci-Hub.
*   `src/config.py` — Конфигурация проекта и настройки окружения.
*   `main.py` — Точка входа для запуска пакетной обработки.
*   `data/` — Папка для локальных PDF-файлов.

## Использование

Для запуска анализа списка препаратов выполните:

```bash
python main.py
```

## API (для интерфейса)

API переехал в `apps/api`. Для запуска используйте README в корне репозитория.

## Формат выходных данных

Результат возвращается в виде структурированного JSON (через `raw_response` от YandexGPT):

```json
{
  "inn": "Название",
  "t1_2": {"value": 7.0, "unit": "h", "comment": "..."},
  "cv_intra": {"value": 30.0, "unit": "%", "comment": "..."},
  "auc": {"value": 2294.0, "unit": "ng*h/mL", "comment": "..."},
  "cmax": {"value": 294.0, "unit": "ng/mL", "comment": "..."},
  "tmax": {"value": 3.0, "unit": "h", "comment": "..."},
  "toxicity": "Описание",
  "bcs_class": "Class 2"
}
```

## Ограничения

*   **Google Scholar:** При частых запросах может потребоваться использование прокси или решение капчи. В системе реализованы случайные задержки (5-15 сек).
*   **Sci-Hub:** Доступность зеркал зависит от вашего региона и настроек DNS.
