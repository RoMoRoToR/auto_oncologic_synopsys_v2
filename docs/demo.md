# Demo сценарий

1. Ввести:
   * МНН: `Rosuvastatin`
   * Форма: `таблетки`
   * Доза: `20 mg`
   * Режим: `натощак`
   * CV: `auto`
2. Нажать **Сгенерировать (Draft)**.
3. Через 1–3 секунды появится **черновик** (DOCX/PDF/JSON/MD/YAML).
4. Нажать **Обогатить источниками** → через 10–30 секунд появятся источники и обновлённые расчёты.

## Что показать жюри

* Дизайн + rationale
* Washout + таймпоинты
* Расчёт выборки с допущениями
* Синопсис (аккордеоны)
* Источники с evidence

## Если нет ключей

* Draft всё равно появляется.
* Источники будут пустыми → warning.
